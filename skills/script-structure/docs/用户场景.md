## 场景一 · 短视频脚本创作师的日常用法

- **角色**：短视频脚本创作师
- **触发时机**：需要「脚本结构生成」这件事有结果的时候
- **他会说**：`用 script-structure 帮我写脚本`
- **需要准备**：选题或主题；目标时长或字数
- **拿到什么**：结构化脚本 / 分镜表
- **容易踩的坑**：把文章直接念出来不是口播稿，必须按呼吸与节奏改写

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 script-structure 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 选题或主题 | ✅ | 缺失会导致输出不可用 |
| 目标时长或字数 | ✅ | 缺失会导致输出不可用 |
| 平台 | ⬜ | 有则更好 |
| 人设语气 | ⬜ | 有则更好 |
| 是否需要分镜 | ⬜ | 有则更好 |
