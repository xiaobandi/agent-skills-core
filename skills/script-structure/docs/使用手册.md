# 使用手册

技能：**脚本结构生成**（`script-structure`）　·　L1 原子技能　·　v1.0.0

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| Agent 平台 | WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作中任一 |
| Python | 3.8+（**仅当本技能自带脚本时需要**；纯对话使用不需要） |
| 第三方依赖 | 无（纯提示词技能） |
| 网络 | 无强制要求；Excel/图片类处理在本地完成 |

## 二、安装

### 2.1 目录放置（推荐）

```bash
cp -r script-structure ~/.workbuddy/skills/          # WorkBuddy / 通用
```

### 2.2 各平台差异

| 平台 | 方式 | 注意事项 |
|---|---|---|
| WorkBuddy | 放到 `~/.workbuddy/skills/` | 支持自动触发，也可显式点名 |
| ChatGPT | 上传 zip | 需账号支持 Skills |
| DeepSeek Harness | `新建技能 安装:<repo-url>` | 需要仓库可访问 |
| Kimi Work | 上传 zip / 放目录 | **不会自动调用**，必须显式点名技能 |
| 豆包工作 | `新建技能 安装:<repo-url>` | 触发词识别依赖 description 质量 |

### 2.3 安装后自检

```bash
# 在技能库根目录执行（技能目录内没有 tools/）
python3 tests/run.py
```

校验项：目录名与 `name` 一致、只使用标准字段、正文不含平台专有工具名、触发词中英双语且信息量足够。**任一项不通过，技能在部分平台会静默不加载。**

## 三、快速上手

### 3.1 纯对话方式（零安装）

```text
用 script-structure 技能：<把你的材料贴进来>
```

## 四、参数总表

### 4.1 输入字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 选题或主题 | ✅ | 缺失会导致早退或输出不可用 |
| 目标时长或字数 | ✅ | 缺失会导致早退或输出不可用 |
| 平台 | ⬜ | 提升质量，缺失不阻塞 |
| 人设语气 | ⬜ | 提升质量，缺失不阻塞 |
| 是否需要分镜 | ⬜ | 提升质量，缺失不阻塞 |

### 4.2 触发词

| 语言 | 触发词 |
|---|---|
| 中文 | 写脚本、脚本结构、分镜表、口播稿、短视频脚本 |
| 英文 | script structure、storyboard、video script |

## 五、输出物说明

**结构化脚本 / 分镜表**

```markdown
| 时间 | 段落 | 口播 | 镜头 |
## 节奏检查
```

交付前逐条核对：

- [ ] 总时长与目标一致（±10%）
- [ ] 钩子在 3 秒内出现

## 六、排错手册

按「症状 → 原因 → 处理」组织。表里的每一条都来自真实使用中撞出来的问题。

| # | 症状 | 原因 | 处理 |
|---|------|------|------|
| 1 | 已知坑（详见 SKILL.md） | 把文章直接念出来不是口播稿 | 必须按呼吸与节奏改写 |
| 2 | 已知坑（详见 SKILL.md） | 分镜写太细会限制拍摄，写太粗等于没写——以'一镜一信息'为准 | 按上文说明调整后重跑 |
## 七、耗时与成本

| 模式 | 耗时 | 成本 |
|---|---|---|
| 对话模式 | 取决于平台与上下文长度 | 按平台计费 |
