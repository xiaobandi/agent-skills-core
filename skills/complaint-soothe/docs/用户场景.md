## 场景一 · 电商评价管理与差评拦截的日常用法

- **角色**：电商评价管理与差评拦截
- **触发时机**：需要「差评安抚话术」这件事有结果的时候
- **他会说**：`用 complaint-soothe 帮我安抚话术`
- **需要准备**：差评内容
- **拿到什么**：分层安抚话术模板
- **容易踩的坑**：第一句就辩解是最大的雷，会引爆二次舆情

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 complaint-soothe 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 差评内容 | ✅ | 缺失会导致输出不可用 |
| 品牌口径 | ⬜ | 有则更好 |
| 可提供的补偿范围 | ⬜ | 有则更好 |
