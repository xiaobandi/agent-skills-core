## 场景一 · 出海冷启动获客官的日常用法

- **角色**：出海冷启动获客官
- **触发时机**：需要「平台格式适配」这件事有结果的时候
- **他会说**：`用 platform-format-adapter 帮我平台适配`
- **需要准备**：主稿（标题 + 正文）；目标平台列表
- **拿到什么**：按平台分段的多个版本，每段含标题 / 正文 / 标签 / 语气提示
- **容易踩的坑**：只改字数不改语气，等于没适配——小红书要口语和第一人称，公众号要有小标题分层

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 platform-format-adapter 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 主稿（标题 + 正文） | ✅ | 缺失会导致输出不可用 |
| 目标平台列表 | ✅ | 缺失会导致输出不可用 |
| 各平台历史爆款风格 | ⬜ | 有则更好 |
| 账号人设语气 | ⬜ | 有则更好 |

---

## 场景三 · 接进自动化链路

脚本是纯函数（文件进 / stdout 出 / 退出码表达判定），可以直接被 CI、定时任务调用：

```bash
python3 scripts/format_adapter.py --file examples/input/main.md --platforms '小红书,抖音'
```

| 退出码 | 含义 | 链路里应该怎么做 |
|---|---|---|
| 0 | 通过 | 继续下一步 |
| 1 | 警告 | 记入待办，不阻塞 |
| 2 | 阻断 | **中断流程**并转人工 |
