## 场景一 · 出海冷启动获客官的日常用法

- **角色**：出海冷启动获客官
- **触发时机**：需要「定时排期 / 云端巡检」这件事有结果的时候
- **他会说**：`用 scheduled-dispatch 帮我排期`
- **需要准备**：内容池或任务池；起始日期
- **拿到什么**：按日期排列的排期表
- **容易踩的坑**：排期不是承诺——素材未就绪时要能一键回退，需标出'素材依赖'

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 scheduled-dispatch 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 内容池或任务池 | ✅ | 缺失会导致输出不可用 |
| 起始日期 | ✅ | 缺失会导致输出不可用 |
| 各平台最佳发布时段 | ⬜ | 有则更好 |
| 人力约束 | ⬜ | 有则更好 |
| 节假日规则 | ⬜ | 有则更好 |

## 场景三 · 接进自动化链路

脚本是纯函数（文件进 / stdout 出 / 退出码表达判定），可以直接被 CI、定时任务调用：

```bash
python3 scripts/schedule_plan.py --pool examples/input/pool.json --start 2026-09-29 --days 7
```

| 退出码 | 含义 | 链路里应该怎么做 |
|---|---|---|
| 0 | 通过 | 继续下一步 |
| 1 | 警告 | 记入待办，不阻塞 |
| 2 | 阻断 | **中断流程**并转人工 |
