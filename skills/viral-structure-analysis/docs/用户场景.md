> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 爆款选题策划师的日常用法

- **角色**：爆款选题策划师
- **触发时机**：需要「爆款结构分析」这件事有结果的时候
- **他会说**：`用 viral-structure-analysis 帮我爆款分析`
- **需要准备**：内容样本（标题 + 正文/脚本，可多条）；样本的互动数据（若有）
- **拿到什么**：结构模板 + 特征权重表 + 填空模板
- **容易踩的坑**：幸存者偏差：只看了爆款没看同等结构的失败样本，会把噪声当规律

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 viral-structure-analysis 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 内容样本（标题 + 正文/脚本，可多条） | ✅ | 缺失会导致输出不可用 |
| 样本的互动数据（若有） | ✅ | 缺失会导致输出不可用 |
| 赛道 | ⬜ | 有则更好 |
| 平台 | ⬜ | 有则更好 |
