**关联分析（关键）**：

- **基数校正**：把点赞绝对值当唯一标准会误导——木里香爆款率 6.2%、苔屿 2.8%，**基数不同**。S3（苔屿 9200）在其 2.8% 爆款率体系内属高位，不能仅因点赞低于 S1（3.2 万）就判「弱」。
- **相关≠因果**：5 条样本里「数字锚点」出现 3 次，但 S1/S3 无数字同样爆——**数字锚点是常见手法，不是爆款原因**。
- **幸存者偏差**：本表**只统计了爆款**，没有同等结构的失败样本，因此「共性」只能说明「爆款里常见」，**不能反推「照做就爆」**。
