# 使用手册

技能：**爆款结构分析**（`viral-structure-analysis`）　·　L1 原子技能　·　v1.0.0

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| Agent 平台 | WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作中任一 |
| Python | 3.8+（**仅当本技能自带脚本时需要**；纯对话使用不需要） |
| 第三方依赖 | 无（纯提示词技能） |
| 网络 | 无强制要求；Excel/图片类处理在本地完成 |

## 二、安装

### 2.1 目录放置（推荐）

```bash
cp -r viral-structure-analysis ~/.workbuddy/skills/          # WorkBuddy / 通用
```

### 2.2 各平台差异

| 平台 | 方式 | 注意事项 |
|---|---|---|
| WorkBuddy | 放到 `~/.workbuddy/skills/` | 支持自动触发，也可显式点名 |
| ChatGPT | 上传 zip | 需账号支持 Skills |
| DeepSeek Harness | `新建技能 安装:<repo-url>` | 需要仓库可访问 |
| Kimi Work | 上传 zip / 放目录 | **不会自动调用**，必须显式点名技能 |
| 豆包工作 | `新建技能 安装:<repo-url>` | 触发词识别依赖 description 质量 |

### 2.3 安装后自检

```bash
# 在技能库根目录执行（技能目录内没有 tools/）
python3 tests/run.py
```

校验项：目录名与 `name` 一致、只使用标准字段、正文不含平台专有工具名、触发词中英双语且信息量足够。**任一项不通过，技能在部分平台会静默不加载。**

## 三、快速上手

### 3.1 纯对话方式（零安装）

```text
用 viral-structure-analysis 技能：<把你的材料贴进来>
```

## 四、参数总表

### 4.1 输入字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 内容样本（标题 + 正文/脚本，可多条） | ✅ | 缺失会导致早退或输出不可用 |
| 样本的互动数据（若有） | ✅ | 缺失会导致早退或输出不可用 |
| 赛道 | ⬜ | 提升质量，缺失不阻塞 |
| 平台 | ⬜ | 提升质量，缺失不阻塞 |

### 4.2 触发词

| 语言 | 触发词 |
|---|---|
| 中文 | 爆款分析、拆解爆款、结构分析、为什么这个火了、内容拆解 |
| 英文 | viral structure analysis、content teardown |

## 五、输出物说明

**结构模板 + 特征权重表 + 填空模板**

```markdown
## 结构切分（样本 → 段落）
## 高频手法与出现频次
## 特征权重表
## 填空模板
```

交付前逐条核对：

- [ ] 样本量不足时明确标注结论为'探索性'
- [ ] 区分相关与因果，不把'这条爆了'简单归因于某个词

## 六、排错手册

按「症状 → 原因 → 处理」组织。表里的每一条都来自真实使用中撞出来的问题。

| # | 症状 | 原因 | 处理 |
|---|------|------|------|
| 1 | 幸存者偏差 | 只看了爆款没看同等结构的失败样本，会把噪声当规律 | 按上条描述调整输入、阈值或措辞后重跑；仍不成立则标注后转人工 |
| 2 | 已知坑（详见 SKILL.md） | 样本少于 5 条时统计意义很弱，需显式提醒 | 按上文说明调整后重跑 |
