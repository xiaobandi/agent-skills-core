# 使用手册

技能：**粉丝分层打标**（`fan-segment-tag`）　·　L1 原子技能　·　v1.0.0

---

## 一、环境要求

| 项 | 要求 |
|---|---|
| Agent 平台 | WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作中任一 |
| Python | 3.8+（**仅当本技能自带脚本时需要**；纯对话使用不需要） |
| 第三方依赖 | 无（纯提示词技能） |
| 网络 | 无强制要求；Excel/图片类处理在本地完成 |

## 二、安装

### 2.1 目录放置（推荐）

```bash
cp -r fan-segment-tag ~/.workbuddy/skills/          # WorkBuddy / 通用
```

### 2.2 各平台差异

| 平台 | 方式 | 注意事项 |
|---|---|---|
| WorkBuddy | 放到 `~/.workbuddy/skills/` | 支持自动触发，也可显式点名 |
| ChatGPT | 上传 zip | 需账号支持 Skills |
| DeepSeek Harness | `新建技能 安装:<repo-url>` | 需要仓库可访问 |
| Kimi Work | 上传 zip / 放目录 | **不会自动调用**，必须显式点名技能 |
| 豆包工作 | `新建技能 安装:<repo-url>` | 触发词识别依赖 description 质量 |

### 2.3 安装后自检

```bash
# 在技能库根目录执行（技能目录内没有 tools/）
python3 tests/run.py
```

校验项：目录名与 `name` 一致、只使用标准字段、正文不含平台专有工具名、触发词中英双语且信息量足够。**任一项不通过，技能在部分平台会静默不加载。**

## 三、快速上手

### 3.1 纯对话方式（零安装）

```text
用 fan-segment-tag 技能：<把你的材料贴进来>
```

## 四、参数总表

### 4.1 输入字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 粉丝/客户互动数据或消费数据 | ✅ | 缺失会导致早退或输出不可用 |
| 分层规则（RFM 等） | ⬜ | 提升质量，缺失不阻塞 |
| 运营目标 | ⬜ | 提升质量，缺失不阻塞 |

### 4.2 触发词

| 语言 | 触发词 |
|---|---|
| 中文 | 粉丝分层、客户分层、打标签、铁粉识别、会员分层 |
| 英文 | fan segmentation、customer tagging、tiering |

## 五、输出物说明

**分层名单 + 每层运营建议**

```markdown
| 分层 | 判定标准 | 人数 | 建议动作 | 触达频次上限 |
```

交付前逐条核对：

- [ ] 分层标准可复现（换成别人算结果一致）
- [ ] 触达频次符合平台对骚扰的限制

## 六、排错手册

按「症状 → 原因 → 处理」组织。表里的每一条都来自真实使用中撞出来的问题。

| # | 症状 | 原因 | 处理 |
|---|------|------|------|
| 1 | 已知坑（详见 SKILL.md） | 分层阈值拍脑袋会导致每期人数剧烈波动，需固定口径 | 按上文说明调整后重跑 |
| 2 | 已知坑（详见 SKILL.md） | 私域触达有频率红线，分层后必须先过滤'近 N 天已触达' | 按上文说明调整后重跑 |
