> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 评论区运营官的日常用法

- **角色**：评论区运营官
- **触发时机**：需要「粉丝分层打标」这件事有结果的时候
- **他会说**：`用 fan-segment-tag 帮我粉丝分层`
- **需要准备**：粉丝/客户互动数据或消费数据
- **拿到什么**：分层名单 + 每层运营建议
- **容易踩的坑**：分层阈值拍脑袋会导致每期人数剧烈波动，需固定口径

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 fan-segment-tag 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 粉丝/客户互动数据或消费数据 | ✅ | 缺失会导致输出不可用 |
| 分层规则（RFM 等） | ⬜ | 有则更好 |
| 运营目标 | ⬜ | 有则更好 |
