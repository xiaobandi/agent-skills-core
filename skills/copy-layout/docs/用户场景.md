## 场景一 · 电商 AI 商品视觉的日常用法

- **角色**：电商 AI 商品视觉
- **触发时机**：需要「文案排版」这件事有结果的时候
- **他会说**：`用 copy-layout 帮我文案排版`
- **需要准备**：文案内容；载体（详情页 / 主图 / 海报）
- **拿到什么**：排版结构稿（模块 / 内容 / 位置 / 字数）
- **容易踩的坑**：文字过多是详情页通病，优先级是'少而准'

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 copy-layout 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 文案内容 | ✅ | 缺失会导致输出不可用 |
| 载体（详情页 / 主图 / 海报） | ✅ | 缺失会导致输出不可用 |
| 模板 | ⬜ | 有则更好 |
| 品牌规范 | ⬜ | 有则更好 |
