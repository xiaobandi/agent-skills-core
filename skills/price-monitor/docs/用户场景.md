# 用户场景

按「谁 → 什么情况下 → 说什么 → 得到什么 → 注意什么」组织。每个场景都能照着跑一遍。

---

> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 多平台铺货与库存同步的日常用法

- **角色**：多平台铺货与库存同步
- **触发时机**：需要「价格监控」这件事有结果的时候
- **他会说**：`用 price-monitor 帮我价格监控`
- **需要准备**：竞品价格数据（含时间戳）
- **拿到什么**：异动清单 + 应对建议
- **容易踩的坑**：到手价含券，凭标价对比会误判

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 price-monitor 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 竞品价格数据（含时间戳） | ✅ | 缺失会导致输出不可用 |
| 自身定价 | ⬜ | 有则更好 |
| 成本 | ⬜ | 有则更好 |
| 监控阈值 | ⬜ | 有则更好 |

---

## 场景三 · 接进自动化链路

脚本是纯函数（文件进 / stdout 出 / 退出码表达判定），可以直接被 CI、定时任务调用：

```bash
python3 scripts/anomaly_detect.py --file examples/input/metrics.json
```

| 退出码 | 含义 | 链路里应该怎么做 |
|---|---|---|
| 0 | 通过 | 继续下一步 |
| 1 | 警告 | 记入待办，不阻塞 |
| 2 | 阻断 | **中断流程**并转人工 |
