## ④ 如实说明

- **材料匹配度**：高。`01` 提供的官方描述原文正是本技能的典型输入；`07` 提供语气与人设约束。
- **`<待填>` 清单**：无。改写不新增数字，事实全部回指 `01`。
- **未完成步骤与原因**：步骤 4 的「AI 味评分下降」自检未通过——不是流程未执行，而是脚本指标与「口语化」目标方向不一致。已如实标注，未粉饰。
- **业务红线拦截情况**：本稿用于对外内容，已剔除空泛/夸大表述；未涉及成本、供应链、隐私；未贬低竞品；未做绝对化承诺（「最好闻」「100% 纯天然」等违规表述不在本输入内，由同族 `compliance-word-scan` 处理）。
- **发现（技能暴露的问题）**：
  1. **AI 味指标奖励「书面长句」**：`ai_score = 套话密度×8 + (0 if 句长方差>60 else 20)`。原文书面长句方差 71.4 → 免加 20 → 0 分；口语短句方差只有 64.1，一旦落入 ≤60 区间反而被加 20 分。**这会让「越口语分越高」的目标失效**。
  2. **「最后」是假阳性套话标记**：`AI_TRACE_MARKERS` 里的「最后」在口语叙述（「最后剩一点点琥珀」）中完全自然，却按套话计分。建议对同一标记按位置/搭配做上下文豁免，或在口语化场景去掉该词。
  3. 步骤 4 的措辞「复检 AI 味评分是否下降」隐含「改写必然降分」的预期，但脚本并不能保证；建议 SKILL 改为「复检并解释评分变化」，避免形成无法通过的自检。
