> ⚠️ 本技能尚未填写真实场景（`scenarios`），下面为**通用推导**，信息量有限。

## 场景一 · 评论区运营官的日常用法

- **角色**：评论区运营官
- **触发时机**：需要「回复话术生成」这件事有结果的时候
- **他会说**：`用 reply-copy-generator 帮我回复话术`
- **需要准备**：待回复内容（一条或多条）；人设约束
- **拿到什么**：分类后的回复草稿表
- **容易踩的坑**：统一话术回复所有评论会被平台判定为营销号行为

---

## 场景二 · 换成你自己的材料

同一句话，把材料换成你手头的真实数据即可：

```text
用 reply-copy-generator 处理下面这份材料：
<粘贴你的内容 / 贴文件路径>
```

**输入结构不要改**：字段名变了，脚本会读不到；缺字段时应当被明确告知缺什么，而不是猜。

| 字段 | 必填 | 说明 |
|---|---|---|
| 待回复内容（一条或多条） | ✅ | 缺失会导致输出不可用 |
| 人设约束 | ✅ | 缺失会导致输出不可用 |
| 场景（评论 / 私信 / 社群 / 评价） | ⬜ | 有则更好 |
| 语气强度 | ⬜ | 有则更好 |
