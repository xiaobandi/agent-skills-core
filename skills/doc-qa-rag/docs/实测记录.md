**## 回答（每句后标 [来源: 文件:片段]）**

**问 1 · 蜡烛冒黑烟**：正常使用无烟，烛芯过长会冒烟，每次点燃前把烛芯剪到 5mm 即可 [来源: 04-知识库与FAQ.md:§一 FAQ#3]。修剪烛芯至 5mm 可防止冒黑烟与火苗过大 [来源: 04-知识库与FAQ.md:§3.3-2]。同时单次燃烧不超过 4 小时 [来源: 04-知识库与FAQ.md:§3.3-3]。大豆蜡燃烧温度低（45–55℃）、无黑烟 [来源: 04-知识库与FAQ.md:§3.1]。家里有婴幼儿或呼吸道敏感人群的，建议改用无火香氛 [来源: 04-知识库与FAQ.md:§3.3-5]。

**问 2 · 养猫能用香薰吗**：建议选无火藤条香氛 [来源: 04-知识库与FAQ.md:§一 FAQ#4]。需注意「无火香氛绝对安全」是误区——无火香氛仍含精油，养宠家庭要避开个别成分（如茶树、柑橘类对猫不友好）[来源: 04-知识库与FAQ.md:§3.4 常见误区]。

**问 3 · 多久发货**：现货 **72 小时**内发货 [来源: 04-知识库与FAQ.md:§一 FAQ#6]。⚠ 该 FAQ 原回答写「48 小时内」，状态列已标「已过期：现为 72 小时内」，故本回答取**现行 72 小时**口径，**不引用**已过期的 48 小时 [来源: 04-知识库与FAQ.md:§一 FAQ#6 状态列]。

**问 4 · 能寄到国外吗**：支持港澳台及日韩 [来源: 04-知识库与FAQ.md:§一 FAQ#14]。⚠ 该 FAQ 原回答「暂不支持」已过期，状态列「已过期：现支持港澳台及日韩」为现行口径 [来源: 04-知识库与FAQ.md:§一 FAQ#14 状态列]。
